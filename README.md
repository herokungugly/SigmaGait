## SigmaGaiT
SigmaGait uses the official [OpenGait](https://github.com/ShiqiYu/OpenGait/tree/master) framework. Get the official SUSTech1k dataset [here](https://lidargait.github.io/). For pseudo-depth generation, use the [WHAM](https://github.com/yohanshin/WHAM) model.
